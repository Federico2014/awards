## 如何参与

四类参与方式是：推荐问题、推荐获奖人、纠错、争议申诉。请使用对应的 [Issue 表单](.github/ISSUE_TEMPLATE/)，阅读[参与指南](docs/zh/contributing.md)及[行为准则](docs/zh/code-of-conduct.md)，并提供可以公开核查的证据。请勿在公开 Issue 中提交私人信息。

## 仓库维护

模板、校验命令和数据生成方式见[记录指南](docs/zh/records.md)。源记录位于 `awards/` 和 `candidates/`，`data/*.json` 为自动生成的汇总。
