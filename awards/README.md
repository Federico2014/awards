# Confirmed awards / 已确认授奖

Only confirmed, publicly announced award entries belong here. 此目录的成果条目仅用于已确认并公示的授奖。

No live batches exist yet. Create a dated batch such as `2026-01/` only when verification is complete, recipients have provided written confirmation, and the award is publicly announced.

目前没有真实批次。仅在核验完成、获奖人书面确认并公示授奖时，创建例如 `2026-01/` 的批次。示例模板位于 docs/templates/，不在此处建立空授奖批次。

Each batch has `batch.yaml`. Each award directory contains `award.yaml`, bilingual `citation.md` and `recipients.md`, and `verification/record.yaml`; a formal claim additionally requires `verification/statement.yaml`.

See the [record guide](../docs/records.md) / [记录指南](../docs/zh/records.md). Use [templates](../docs/templates/) outside this live directory for examples.
