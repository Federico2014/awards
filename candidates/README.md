# Public candidates / 公开候选池

- `verified-pending/`: formal candidates under verification or awaiting written recipient confirmation. 正式候选，已进入核验或等待获奖人书面确认。
- `observation/`: candidates with incomplete independent verification or priority review. 观察候选，独立核验或优先权审查尚未完成。

Neither category is an award. Both use the award record layout, including `verification/`. For the formal channel, `statement.yaml` is mandatory even while review is pending. 两类均不表示获奖，都使用包含核验目录的完整条目结构；主张形式化通道时必须提供陈述文件。

Keep IDs stable when moving entries. An ID can occur only once across candidates and awards. 候选转授奖时保持 ID 不变；同一 ID 不得同时出现在多处。

See [records](../docs/records.md) / [记录指南](../docs/zh/records.md).

The framework references 12 formal and 3 observation candidates, but their source records have not been supplied. No placeholder candidates are invented to meet these counts.

框架提及 12 项正式候选、3 项观察候选，明细尚未提供；不为凑数建立虚构候选。
