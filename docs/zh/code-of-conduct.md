# 行为准则

[English](../../CODE_OF_CONDUCT.md)

请共同维护一个尊重他人、适合数学讨论、独立核验和善意分歧的环境。

- 讨论证据与推理，批评主张而不攻击个人。
- 尊重不同背景、语言与经验水平。
- 披露相关利益冲突并遵守回避安排。
- 不得骚扰、歧视、威胁、冒充他人、公开私人信息或持续扰乱讨论。
- 尊重停止不受欢迎联系的要求。

本准则适用于仓库 Issue、PR、代码审查及其他项目管理的空间。维护者可按行为严重程度要求修改、隐藏或删除不当内容、锁定讨论或限制参与；在可行时说明理由，并提供由无相关冲突的维护者复核的途径。

不涉及敏感信息的行为问题，可在相关公开讨论中提醒维护者，避免重复有害内容。**保密举报联系人及独立申诉联系人尚未指定**；敏感报告不要发布在公开 Issue 中，这些渠道须在项目正式启动前落实。有利益冲突的维护者不应决定相关报告。
